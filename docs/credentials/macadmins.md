# MacAdmins SOFA Feed — credential setup

[← back to collector docs](../collectors/macadmins.md)

No credentials needed — the SOFA (Simple Organized Feed for Apple Software
Updates) feed maintained by the MacAdmins Open and Free Software project is
free and unauthenticated. There is nothing to provision in a vendor console.

## Record the credentials

Nothing to record — `CCM("macadmins")` needs no config and no environment
variables to run.
